Hostel Record Management System

1. Project Name

Hostel Record Management System

2. Introduction

The Hostel Record Management System is a simple Python-based project used to manage student hostel records. It allows the user to add, view, search, update, and delete student information.

The system stores the records in a JSON file so that the data can be used again when the program is opened.

3. Features

- Add new student record
- View all student records
- Search student using roll number
- Update student information
- Delete student record
- Store data permanently using JSON
- Simple menu-based interface

4. Information Stored

The system stores:

- Roll Number
- Student Name
- Room Number
- Branch
- Phone Number

5. Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists
- Dictionaries
- Conditional Statements
- Loops
